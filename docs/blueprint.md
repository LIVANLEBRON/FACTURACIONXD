# **App Name**: Invoicify

## Core Features:

- Customer Management: Allow users to add customer details like name, address, and contact information.
- Invoice Creation: Enable users to create invoices with fields for items, descriptions, quantities, and prices.
- Invoice Overview: Provide a simple interface for viewing, editing, and deleting invoices.

## Style Guidelines:

- Primary color: Light blue (#E3F2FD) for a professional feel.
- Secondary color: Grey (#B0BEC5) for text and backgrounds.
- Accent: Teal (#4DB6AC) for interactive elements and highlights.
- Clean and organized layout for easy navigation.
- Simple and professional icons for key actions (e.g., add, edit, delete).
- Subtle transitions for a smooth user experience.
